Classic playable Tetris baseline with keyboard movement and rotation, gravity, line clearing, scoring, levels, game over and restart.

The responsive Canvas board includes game information, keyboard help and two gameplay buttons. Pause/resume preserves timing; leaving the page pauses play.

Download tetris.html directly or extract tetris-browser.zip. SHA256SUMS.txt verifies both assets. All application code is embedded in the HTML.

Verified with 38 local checks using Chromium headless shell and managed Firefox on Linux. Firefox required a process-local content-sandbox override on this execution host. Native OS focus delivery and headed browsers were not tested. Modern rules, configuration, penetration and persistence arrive in later phases.
